What it copies

Only files you authored through the game are eligible. Everything else in the folder is left where it is.

Category Files Contents
Gameplay cs2_user_convars_*.vcfg, config.cfg Sensitivity, crosshair, HUD, gameplay cvars
Keybinds cs2_user_keys_*.vcfg, user_keys*.vcfg Keyboard and mouse bindings
Video cs2_video.txt, video.txt Resolution and graphics choices
Autoexec autoexec.cfg Your own startup commands

Machine-generated settings, unknown files, steam_autocloud.vdf, and remotecache.vdf are deliberately excluded.

How it works

Three steps, and nothing is written until you confirm the last one.

  1. Pick the two accounts

    Steam accounts already used on this PC are detected automatically, with their persona name, account ID, and locally cached avatar.

  2. Choose what to copy

    Turn gameplay, keybinds, video, or autoexec on and off. The preview lists each file by name and says whether it is new or replaces an existing one.

  3. Close Steam and migrate

    The app stages the files, backs up what it will overwrite, copies, and verifies. If anything fails, it rolls back.

What it does to protect your files

Config folders are easy to break and annoying to rebuild, so the app is deliberately conservative.

  • Steam and CS2 must both be closed before any write begins.
  • Steam is asked to exit with steam.exe -shutdown; no process is ever force-killed.
  • Files are staged on the destination drive and SHA-256 verified before and after copying.
  • Replaced files are backed up to %LOCALAPPDATA%\CS2Migrate\Backups with a readable JSON manifest.
  • Only the selected, recognised files are touched. The destination folder is never mirrored or emptied.
  • If a write or a checksum fails, every changed file is restored from the backup.

About Steam Cloud

Steam Auto-Cloud syncs configured files when a game starts and stops, so a fully closed Steam client — not deleted metadata — is the safe boundary for a migration. The app keeps a sealed copy of what it wrote; if Cloud later restores older settings, it detects the checksum mismatch and offers to reapply that copy.

Install and run

  1. Download CS2Migrate.exe.
  2. Double-click it. There is nothing to install and no administrator prompt.
  3. Close Steam when the app asks, review the preview, then migrate.

Requires Windows 10 or 11, 64-bit. Builds from main are not code-signed, so SmartScreen may warn on first run — compare the checksum if you want to be sure.

Questions

Does this touch my friend's settings permanently?

Only if you want it to. Turn on the temporary session switch before migrating onto a borrowed account: the app protects the exact original state and its main button becomes "Restore friend's settings", which puts everything back and removes the files it added.

Where do the backups go?

Into %LOCALAPPDATA%\CS2Migrate\Backups, outside every Steam folder, with a JSON manifest listing each file and its checksum. The app has a button that opens that folder.

Can I use it between two PCs?

No. It reads the Steam userdata folder of the machine it runs on, so both accounts have to have been signed in on that PC at least once.

Why does Windows warn me about the download?

The executable is built by GitHub Actions and is not code-signed, which is enough for SmartScreen to flag it as unrecognised. The SHA-256 above matches the build published here, and the workflow that produced it is in the repository.
