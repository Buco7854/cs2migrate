Designed around your files

Careful where it matters.

The original script was a useful proof of concept. The app turns it into a previewable transaction with guardrails at every write.

⌁
01

Steam-aware

Migration stays locked while Steam or CS2 is running. The app uses Steam’s normal shutdown command and never force-kills it.

◫
02

Backup first

Every matching target file and a sealed recovery copy are saved outside Steam’s folders with a readable JSON manifest.

◇
03

Verified twice

Files are SHA-256 checked after staging and after commit. A failed transaction rolls back what it changed.

⊘
04

Friend mode

Borrow an account without leaving your setup behind. One click later restores the friend’s exact original configuration.

Three calm steps

From fragging to fragging.

Account discovery and local profile images make it hard to pick the wrong player. A precise preview makes the final action obvious.

  1. 1

    Pick the source and target

    Steam accounts already used on this PC appear automatically, with persona names, account IDs, and cached avatars.

  2. 2

    Choose exactly what moves

    Toggle gameplay, keybinds, video, or autoexec. See which target files are new and which will be replaced.

  3. 3

    Close Steam and migrate

    The app stages, backs up, commits, and verifies. If Steam Cloud restores old settings later, the sealed copy can be reapplied.
